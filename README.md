**摘要**

> 800字内
>
> 本作品旨在解决当前老年人群体在用药过程中存在的安全隐患与管理困难。随着人口老龄化加剧，老年人多病共存、记忆力减退、辨识能力下降等问题日益突出，容易造成漏 服、误服、重复服药等风险，严重影响身体健康与生命安全。同时，缺乏对儿童接触药 物的有效防范，也可能带来意外风险。因此，本系统通过融合智能识别、人机交互与远 程管理技术，提升老人用药的规范性、便捷性与安全性，减轻家属照护压力，推动智慧 健康养老的发展。

**第一部分 作品概述**

1.  功能与特性

> 400字内（可加重要图）；
>
> 本作品的主要功能有：①身份绑定：通过指纹模块实现药箱使用者身份的绑定，实现只有使用者才能打开药箱。②药物录入：通过OpenMV扫描药品条码，在屏幕上完成药物服用频次后即完成药物录入。③药物移除：点按屏幕要移除药物所在格子序号即可移除药物。④定时提醒：当有药物的服用时间到达时，通过语音合成、LED等实现对应服药物的信息提示和位置提示，具有声、光多重提醒。⑤小程序：系统连接小程序，小程序可接收未及时服药等紧急情况的报警，还可以修改药物的服用时间。⑥病情分析：根据当前药箱存在药物及服用情况等数据，通过DeepSeek进行病情的分析并通过文字显示和语音合成输出。

2.  应用领域

> 400字内（可加重要图）；
>
> 本系统广泛适用于居家养老、智慧医疗、社区诊所、慢性病随访等场景，特别是老龄化家庭和独居老人的用药管理需求场景，通过物联网手段提升家庭健康管理的效率和安全性。

3.  主要技术特点

> 400字内；
>
> 本系统采用HMI-Board与星火1号主控协同通信，通过CAN总线传输命令，SPI传输数据，实现用药信息的交互和执行控制。语音交互系统结合了语音识别与大语言模型分析能力，为用户提供自然语言交互体验。药品管理模块依赖OpenMV完成药品条码扫描，结合GUI界面实现用户身份操作与药品操作的可视化反馈。用药提醒与报警功能通过MQTT协议与小程序通信，确保家属及时获取老人的服药状态与异常信息。系统整体设计强调实时性、安全性与智能化，适应老年人操作习惯。

4.  主要性能指标

> 200字内（建议用表格）；

系统响应时间：≤5秒（语音交互及提醒触发）

指纹识别准确率：≥98%

药品信息识别准确率：≥95%（条码识别）

报警信息上报延迟：≤2秒（网络稳定状态下）

药品信息录入容量：5种

系统掉电数据保持：支持断电数据存储与恢复

支持多种用药提醒方式（语音+GUI）

5.  主要创新点

> 200字以内（逐点给出）；

（1）结合语音识别与大模型推理，实现用药智能交互与病情辅助分析；

（2）采用双主控架构（HMI-Board+星火1号）实现指令与数据分离，提高系统稳定性；

（3）引入指纹识别与电子锁，提升药品使用安全性；

（4）利用条码扫描与远程小程序联动，实现药品信息录入与家属同步管理；

（5）系统具备异常检测与报警功能，全面保障老年用户用药过程。

> 本系统采用“HMI-Board+星火1号”双核心设计，通过 CAN总线传输控制命令，SPI传输数据，构成高效可靠的主从通信体系。其中：

- HMI-Board主要负责人机交互，包括身份识别、药品操作界面、语音交互和表情反馈显示；

- 星火1号主控模块负责核心数据管理与外设控制，包括指纹识别、药品扫描、定时控制和状态回传；

- OpenMV模块配合星火1号进行药品条形码识别；

- 小程序端通过MQTT实现与星火1号的信息交互，负责信息修改、用药提醒、应急报警等远程功能；

- 整体系统通过GUI与语音提供完整的人机界面，通过指纹与传感器加强用药安全，并可与家属远程联动。

> 2.2.1 硬件整体介绍；
>
> HMI-Board：
>
> 作为系统的人机交互核心，配有触控显示屏，主要完成以下任务：

- 通过GUI界面实现身份操作、药物操作、信息与文字显示等功能；

- 接收星火1号下发的用药提示、状态反馈等信息；

- 通过 CAN总线向星火1号发送控制指令，通过 SPI 接收数据流（药物信息等）。

- 接入DeepSeek，辅助分析用药合理性或健康建议。

- 语音交互：

> 与用户沟通用药信息、提醒时间等内容
>
> 语音识别模块：识别特定指令，传回主控板以执行相关操作
>
> 语音合成模块：将DeepSeek回复和药物信息等进行语音合成与播放
>
> 星火1号：

- 核心计算板及各类板载资源

- 利用搭载RW007WIFI模块，连接互联网以接入天气等信息，实现与小程序的交互

- 串口连接OPENMV识别药物信息，并对对应药盒进行服药时间等处理

- AT806指纹模块进行身份确认，防止误食

- 配置舵机电机锁住药盒，在服药时间打开，或身份验证后打开以应对特殊需求

- RTC计时保证服药时间提醒精确，不因低功耗模式产生错误

- 灯带对须服用的药格进行高亮处理，提示用药种类
